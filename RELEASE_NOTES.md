## Download

| File | What it is |
|---|---|
| `Poltergaeist-Setup.exe` | Installer (recommended). Starts at sign-in, with an uninstaller. |
| `Poltergaeist-portable.zip` | No install. Unzip and run `Poltergaeist.exe`. Does not start with Windows. |

Windows SmartScreen may warn that the publisher is unknown because the app is
not code-signed. Choose **More info**, then **Run anyway**.

## Please read first

Poltergæist is a haunting app. It cannot be paused: stop it in Task Manager,
restart the PC, or uninstall it. It includes a very bright flash and a loud ring.
Install it only on your own computer, and not where someone with photosensitive
epilepsy may be using it. See the [README](https://github.com/Brage1025/Poltergaeist#readme).
